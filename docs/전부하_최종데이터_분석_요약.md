## 2. W열 "평균값 데이터" 행 규칙

- **장비(학교코드·메모1)당**: **1200행** = **600 DL + 600 UL**
  - 다운로드 측정 600개(10분 구간) + 업로드 측정 600개(10분 구간)
- "학교별로 장비마다 600개" → **DL 600개, UL 600개**로 해석하면, 장비당 **총 1200행**이 맞음.
- 일부 학교·장비는 1200 미만(2400, 3600, 6000, 8400 등): 장비 수·차수별 포함 여부 차이로 추정.

## 4. 사용 시 참고

- **필터**: `df[df["평균값 데이터"] == "평균값 데이터"]` 로 W열 기준 행 추출.
- **그룹 키**: `학교코드`, `메모1`(장비 식별).
- **DL/UL 구분**: 같은 행에서 DL 열이 채워진 600개 = 다운로드 구간, UL 열이 채워진 600개 = 업로드 구간.
- **표8 전부하 일괄업로드** 등 downstream 작업 시: 위 필터 적용 후 학교·장비별로 600(DL) 또는 600(UL) 단위로 잘라 사용하면 됨.
